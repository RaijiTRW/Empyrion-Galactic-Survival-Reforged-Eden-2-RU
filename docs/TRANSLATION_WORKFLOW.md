# Процесс перевода

## После получения файлов мода

1. Зафиксировать версию Reforged Eden 2.
2. Найти все файлы с пользовательским текстом.
3. Составить список переводимых CSV/YAML-файлов.
4. Проверить кодировку и разделители CSV.
5. Перевести строки с сохранением ключей, плейсхолдеров и тегов.
6. Проверить валидность CSV/YAML.
7. Собрать папку `translation/`.
8. Обновить README и changelog.
9. Сделать commit.

## Что нельзя ломать

- количество колонок в CSV;
- порядок строк, если игра ожидает его;
- технические идентификаторы;
- плейсхолдеры;
- теги форматирования;
- пути к файлам;
- имена YAML-полей.
