# Empyrion Galactic Survival - Reforged Eden 2 Русификатор

Русификатор для сценария/мода **Reforged Eden 2** в игре **Empyrion - Galactic Survival**.

Репозиторий готовится как открытый набор файлов перевода: его можно скачать, установить вручную в папку игры и использовать вместе с установленным Reforged Eden 2.

> Сейчас это заготовка репозитория. Файлы перевода будут добавлены после разбора актуальной версии мода Reforged Eden 2.

## Что будет переведено

- интерфейсные строки сценария;
- описания предметов, блоков, технологий и ресурсов;
- PDA/квесты/журнал заданий;
- диалоги, если они есть в переданной версии мода;
- дополнительные CSV/YAML-файлы сценария, где есть игровой текст.

## Как скачать

Когда русификатор будет опубликован на GitHub:

1. Откройте страницу репозитория.
2. Нажмите **Code**.
3. Выберите **Download ZIP**.
4. Распакуйте архив в удобное место.

Если на странице есть готовый релиз:

1. Откройте раздел **Releases**.
2. Скачайте последний архив русификатора.
3. Распакуйте его.

## Установка для новой игры

Используйте этот способ, если вы только собираетесь начать новую игру в Reforged Eden 2.

1. Установите **Empyrion - Galactic Survival**.
2. Установите сценарий **Reforged Eden 2** через Steam Workshop или вручную.
3. Откройте папку игры:

```text
Steam/steamapps/common/Empyrion - Galactic Survival/
```

4. Скопируйте содержимое папки русификатора:

```text
translation/Content/
```

5. Вставьте его в папку игры:

```text
Empyrion - Galactic Survival/Content/
```

6. Согласитесь на замену файлов, если система спросит.
7. Запустите игру и начните новую игру со сценарием **Reforged Eden 2**.

## Установка для уже существующего сохранения

Empyrion может копировать часть файлов сценария в папку сохранения. Поэтому для старого сейва иногда нужно заменить файлы не только в папке сценария, но и в папке конкретного сохранения.

1. Сначала выполните установку в папку игры из раздела выше.
2. Откройте папку сохранений:

```text
Steam/steamapps/common/Empyrion - Galactic Survival/Saves/Games/
```

3. Откройте папку нужного сохранения.
4. Если в архиве русификатора есть папка:

```text
translation/Saves/Games/_SAVE_NAME_/
```

скопируйте ее содержимое в папку вашего сохранения.

Пример:

```text
translation/Saves/Games/_SAVE_NAME_/PDA/
```

копируется в:

```text
Empyrion - Galactic Survival/Saves/Games/Название_вашего_сейва/PDA/
```

## Где лежат файлы перевода

Основная папка будущего релиза:

```text
translation/
```

Ожидаемая структура:

```text
translation/
  Content/
    Scenarios/
      Reforged Eden 2/
        Extras/
        PDA/
        Dialogues/
  Saves/
    Games/
      _SAVE_NAME_/
        PDA/
```

Точная структура может измениться после разбора актуальной версии Reforged Eden 2.

## Совместимость

Русификатор будет привязан к конкретной версии Reforged Eden 2, которая будет указана после добавления файлов перевода.

Если мод обновился, часть строк может вернуться на английский или игра может использовать новые файлы. В таком случае нужно обновить русификатор под новую версию мода.

## Важно

- Перед установкой сделайте резервную копию файлов, которые заменяете.
- Для старых сохранений сделайте резервную копию сейва.
- Этот репозиторий не заменяет сам Reforged Eden 2. Сначала установите оригинальный мод/сценарий.
- Оригинальные права на Reforged Eden 2 принадлежат его авторам.
