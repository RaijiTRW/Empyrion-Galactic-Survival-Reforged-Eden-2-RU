# Empyrion Galactic Survival - Reforged Eden 2 Русификатор

Русификатор для сценария **Reforged Eden 2** в игре **Empyrion - Galactic Survival**.

Перевод подготовлен для **Reforged Eden 2 Beta, Build 46** из Steam Workshop.

На данный момент перевод остается актуальным. Обновления Reforged Eden 2 в Steam Workshop отслеживаются, и при изменениях мода русификатор будет обновляться.

Workshop ID мода:

```text
3143225812
```

## Что переведено

- названия и описания предметов, блоков, ресурсов и технологий;
- PDA, задания, главы и сообщения миссий;
- описание сценария.

Перевод сделан через Google Translate и технически проверен: пустых русских строк нет, игровые теги, переносы строк и плейсхолдеры сохранены.

Диалоги NPC временно оставлены в оригинальном английском виде. Переведенный `Dialogues.csv` вызывал пустые окна диалога в уже созданной игре, поэтому он отключен до исправления формата.

Файл `Dialogues.ecf` оставлен оригинальным, потому что это файл логики диалогов.

## Как скачать русификатор

1. Нажмите зеленую кнопку **Code** на странице GitHub.
2. Нажмите **Download ZIP**.
3. Распакуйте скачанный архив.
4. Откройте распакованную папку русификатора.

Внутри нужна папка:

```text
translation/
```

## Где находится Reforged Eden 2

Если мод установлен через Steam Workshop, он обычно лежит здесь:

```text
Steam/steamapps/workshop/content/383120/3143225812/
```

`383120` - это ID игры Empyrion в Steam.

Если папки `3143225812` нет:

1. Откройте папку `Steam/steamapps/workshop/content/383120/`.
2. Отсортируйте папки по дате изменения.
3. Откройте свежие папки.
4. Найдите файл `description.txt`.
5. В нужной папке будет описание Reforged Eden 2.

## Установка: самый простой способ

Этот способ подходит, если вы хотите быстро поставить перевод прямо поверх Workshop-мода.

1. Закройте игру.
2. Откройте папку русификатора.
3. Перейдите в папку:

```text
translation/Content/Scenarios/Reforged Eden 2/
```

4. Скопируйте все файлы и папки изнутри этой папки.
5. Откройте папку Workshop-мода:

```text
Steam/steamapps/workshop/content/383120/3143225812/
```

6. Вставьте скопированные файлы туда.
7. Согласитесь на замену файлов.
8. Запустите игру.
9. Запустите сценарий **Reforged Eden 2**.

Важно: Steam может перезаписать эти файлы после обновления Workshop-мода. Если перевод пропал после обновления, установите русификатор заново.

## Установка: стабильный способ

Этот способ лучше, если вы не хотите, чтобы Steam Workshop случайно перезаписал перевод.

1. Закройте игру.
2. Откройте папку Workshop-мода:

```text
Steam/steamapps/workshop/content/383120/3143225812/
```

3. Скопируйте всю папку `3143225812`.
4. Откройте папку сценариев игры:

```text
Steam/steamapps/common/Empyrion - Galactic Survival/Content/Scenarios/
```

5. Вставьте туда скопированную папку.
6. Переименуйте ее в:

```text
Reforged Eden 2
```

7. Откройте папку русификатора.
8. Скопируйте содержимое папки:

```text
translation/Content/
```

9. Вставьте это в папку игры:

```text
Steam/steamapps/common/Empyrion - Galactic Survival/Content/
```

10. Согласитесь на замену файлов.
11. Запустите игру и выберите локальный сценарий **Reforged Eden 2**.

## Если игра уже создана

Если вы уже начали игру до установки русификатора, одной замены Workshop-папки может быть мало. Empyrion может брать PDA и часть данных сценария из папки уже созданного сохранения.

Сделайте так:

1. Полностью закройте игру.
2. Сначала установите русификатор в папку сценария одним из способов выше.
3. Откройте папку сохранений:

```text
Steam/steamapps/common/Empyrion - Galactic Survival/Saves/Games/
```

4. Откройте папку вашего сохранения.
5. Сделайте резервную копию этой папки.
6. Откройте в русификаторе папку:

```text
translation/Saves/Games/_SAVE_NAME_/
```

7. Скопируйте содержимое этой папки в папку вашего сохранения.
8. Согласитесь на замену файлов.
9. Запустите игру и загрузите сохранение.
10. Откройте консоль клавишей `~`.
11. Выполните команду:

```text
ds reload
```

12. Выполните эту же команду второй раз:

```text
ds reload
```

Команда `ds reload` перезагружает файлы диалогов `Dialogues.ecf` и `Dialogues.csv` в уже запущенной игре. Если PDA все еще старый, лучше полностью выйти из игры и загрузить сохранение заново.

## Как проверить, что перевод поставился

1. Запустите Empyrion.
2. Откройте Reforged Eden 2.
3. Проверьте PDA через клавишу **F1**.
4. Посмотрите описания предметов, блоков или заданий.
5. Если текст на русском, установка прошла успешно.

## Нашли проблему

Если что-то не работает, текст кривой, часть строк осталась на английском или инструкция непонятная, напишите в **Issues**:

[Сообщить о проблеме](https://github.com/RaijiTRW/Empyrion-Galactic-Survival-Reforged-Eden-2-RU/issues)

Пожалуйста, укажите:

1. Версию Reforged Eden 2.
2. Как вы ставили русификатор: в Workshop-папку или в локальную копию сценария.
3. Где проблема: PDA, диалог, описание предмета, установка или другое место.
4. Скриншот, если его можно сделать.
5. Точный английский/русский текст, если проблема в переводе.

Для Issues используются теги:

- `translation` - ошибка или улучшение перевода;
- `installation` - проблема с установкой;
- `bug` - что-то сломалось или не работает;
- `compatibility` - проблема после обновления мода или игры;
- `enhancement` - предложение улучшения;
- `question` - вопрос.

## Как удалить русификатор

Самый простой способ:

1. Удалите измененную папку Reforged Eden 2.
2. В Steam откройте Workshop.
3. Отпишитесь от Reforged Eden 2.
4. Подпишитесь снова, чтобы Steam скачал чистую версию мода.

Если вы ставили перевод в локальную копию сценария, просто удалите папку:

```text
Steam/steamapps/common/Empyrion - Galactic Survival/Content/Scenarios/Reforged Eden 2/
```

## Важно

- Перед заменой файлов сделайте резервную копию мода или сохранения.
- Этот русификатор не содержит весь мод Reforged Eden 2, а только файлы перевода.
- Сначала установите оригинальный Reforged Eden 2.
- После обновления мода перевод может потребовать обновления.
- Reforged Eden 2 принадлежит его авторам.
