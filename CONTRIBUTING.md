# Как помочь с переводом

Спасибо за интерес к русификатору Reforged Eden 2.

## Правила перевода

- Не удаляйте технические ключи строк.
- Не меняйте количество колонок в CSV-файлах.
- Сохраняйте плейсхолдеры, переменные и управляющие теги без изменений.
- Не переводите внутренние идентификаторы предметов, блоков, фракций и квестов, если они используются игрой как ключи.
- Если строка содержит запятые, кавычки или переносы, проверяйте, что CSV остался корректным.

## Стиль

- Русский текст должен быть понятным в игре, без дословной кальки там, где она мешает смыслу.
- Названия фракций, уникальных технологий и специальных терминов лучше сверять с глоссарием.
- Если термин спорный, добавьте заметку в `docs/GLOSSARY.md`.

## Как предложить правку

1. Сделайте fork репозитория.
2. Создайте отдельную ветку.
3. Внесите изменения.
4. Проверьте CSV/YAML.
5. Откройте Pull Request с коротким описанием.
